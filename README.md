# Summary Podcast Bot

Telegram-бот принимает ссылку на публичное YouTube-видео, анализирует его через
Gemini на русском языке и возвращает саммари в формате DOCX.

## Как работает

1. На Render бот принимает сообщения через Telegram webhook; локально использует
   polling.
2. Gemini получает публичную YouTube-ссылку напрямую и анализирует видео целиком.
3. Если прямой анализ недоступен, `yt-dlp` скачивает аудио, после чего бот
   загружает его во временное хранилище Gemini.
4. Gemini формирует русскоязычное саммари, бот создаёт Word-файл и отправляет его
   в Telegram.

Редакторская инструкция хранится отдельно в `prompts/summary_ru.md`. Её можно
менять без правок Python-кода.

Одновременно обрабатывается одно видео, чтобы не расходовать бесплатную квоту
рывками. Временные локальные и загруженные в Gemini файлы удаляются после работы.

## Настройка

1. Установите Python 3.11 или новее.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Скопируйте `.env.example` в `.env` и задайте:

   - `TG_TOKEN` — токен от BotFather;
   - `GEMINI_API_KEY` — ключ из Google AI Studio;
   - `GEMINI_MODEL` — необязательно, по умолчанию `gemini-3.7-flash`.
   - `TELEGRAM_PROXY_URL` — необязательный HTTP/SOCKS5-прокси, если Telegram
     недоступен из вашей сети.

4. Запустите: `python main.py`.

На облачном хостинге задавайте переменные через раздел Secrets/Environment.
Никогда не добавляйте `.env`, cookies или API-ключи в Git.

## Ограничения

- Прямой анализ поддерживает только публичные YouTube-видео.
- Резервное скачивание аудио зависит от доступности YouTube для IP-адреса
  хостинга. Cookies намеренно не используются и не хранятся в репозитории.
- Точные бесплатные квоты зависят от API-ключа и отображаются в Google AI Studio.
- Render автоматически задаёт `RENDER_EXTERNAL_URL`, поэтому отдельно настраивать
  URL webhook не требуется.
